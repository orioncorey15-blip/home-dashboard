Local photo folder (used only when PHOTO_SOURCE is "local" in config.js).

1. Put your photos (.jpg/.png) in this folder. Phone-sized photos (about 1920px wide)
   work best on an old tablet; full-resolution camera files are slow and use lots of memory.
2. Double-click make-photo-list.bat (Windows) or run make-photo-list.sh (Mac/Linux).
   That writes photos.js, the list the dashboard reads.
3. Copy this whole folder to the tablet (home-dashboard/photos). The dashboard picks up
   the new list within an hour, or at once if you reload the page.
